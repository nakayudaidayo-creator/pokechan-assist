# ポケチャン補助(動作確認版)

ポケモンチャンピオンズの対戦補助アプリを作る前に、**Macを使わずに作って入れる流れ**が成り立つかを確かめるための最小アプリです。

この版で確かめること:

1. GitHub Actions で iPhone 用アプリ(.ipa)が作れるか
2. Windows の Sideloadly で iOS 27 の iPhone に入れられるか
3. 小窓(ピクチャ・イン・ピクチャ)がゲームの上に出るか
4. 画面録画の拡張機能が動くか
5. 拡張機能から本体アプリへ情報が届くか(通信 / 共有領域のどちらが使えるか)

---

## 1. GitHub でビルドする

1. 個人用の GitHub アカウントで、**公開(Public)リポジトリ**を作る(例:`pokechan-assist`)
   - 公開リポジトリなら、GitHub Actions の Mac 環境を無料で使えます
   - コードは誰でも見られる状態になります。パスワードなどは入れません
2. このフォルダの中身をすべてリポジトリに置く(`.github` フォルダも忘れずに)
3. リポジトリの **Actions** タブを開く → 「iPhoneアプリをビルド」が動き出す
   - 動いていなければ「Run workflow」を押す
4. 緑のチェックが付いたら、その実行を開く → 下の **Artifacts** から `PokeChanAssist-ipa` をダウンロード
5. ダウンロードした zip を展開すると `PokeChanAssist.ipa` が入っています

赤いバツが付いたら、失敗した手順のログを Claude に見せてください。

## 2. Windows の準備(最初の1回だけ)

1. **iTunes** と **iCloud** を Apple の公式サイトから入れる
   - Microsoft Store 版では Sideloadly が動きません
2. **Sideloadly** を公式サイト(sideloadly.io)から入れる
3. iPhone をケーブルで Windows につなぎ、iPhone 側で「このコンピュータを信頼」を選ぶ

## 3. iPhone に入れる

1. Sideloadly を開き、Apple ID を入力する
   - 外部ツールに Apple ID を入れることになるので、心配ならサブの Apple ID を使ってください
2. `PokeChanAssist.ipa` を Sideloadly にドラッグして **Start** → パスワードを入力
3. iPhone の設定
   - 設定 → プライバシーとセキュリティ → **デベロッパモード** をオン(再起動あり)
   - 設定 → 一般 → **VPNとデバイス管理** → 自分の Apple ID を「信頼」
4. ホーム画面の「ポケチャン補助」を開く

無料の Apple ID では、7日たつとアプリが開けなくなります。Sideloadly で同じ ipa をもう一度入れれば使えます(自動更新の設定もあります)。

## 4. 動作確認

アプリを開いたら、上から順に試して結果を教えてください。

1. **小窓**:「小窓を開始」を押す → ホームに戻ってもゲームを開いても、黒い小窓に時刻が出続けるか
2. **画面録画の拡張**:丸いボタン → 「ポケチャン補助 読み取り」 → 「ブロードキャストを開始」
3. **受け渡し**:小窓の「受信 ○件」が1秒ごとに増えるか。アプリ画面の「通信(UDP)」と「共有領域(App Group)」がそれぞれどうなっているか

うまくいかなかった項目は、画面のスクショを送ってください。

## 中身

| パス | 内容 |
| --- | --- |
| `project.yml` | Xcode プロジェクトの設計図(GitHub Actions 上で XcodeGen が変換) |
| `App/` | 本体アプリ(画面、小窓、受信) |
| `Broadcast/` | 画面録画の拡張機能 |
| `Shared/` | 両方で使う設定 |
| `.github/workflows/build.yml` | GitHub Actions のビルド手順 |
