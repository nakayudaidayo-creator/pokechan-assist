# 選出画面の画像判定(試作)

選出画面の右側に並ぶ相手6匹を、**タイプアイコン → 性別マーク → ポケモンの絵**の順に判定する試作です。iPhone アプリに組み込む前に、ここで方式と精度を確かめています。

| ファイル | 内容 |
| --- | --- |
| `slots.py` | 右側の赤紫の枠を色で見つけ、6枠に分けて、絵・タイプアイコン2つ・性別マークを切り出す |
| `typeicons.py` | タイプアイコンを見本と比べて判定。単タイプの空欄、性別(♂青・♀赤・なし)も判定 |
| `sprites.py` | ポケモンの絵を、色ではなく形(輪郭の向き)で比べる。色違いにも強い |
| `dex_types.json` | ポケモンチャンピオンズに出るポケモンとタイプの一覧(候補の絞り込みに使う) |
| `evaluate.py` | スクショ4枚で「1枚を除いた3枚で見本を作り、残り1枚を判定」を4回くり返して精度を測る |

## 結果(2026-11-05、スクショ4枚・24匹)

- **枠の検出**:4枚とも6枠を正しく検出(枠がつながって見える場合も、間隔から割り出す)
- **タイプアイコン**:43個中42個正解。外れた1個は、こおりの見本が1つしかない状態での判定(見本が増えれば解消する見込み)
- **性別マーク**:24個すべて正解
- **タイプで候補を絞った結果**:24匹中9匹はタイプだけで1匹に決まり、18匹は2匹以内まで絞れた。多かったのはノーマル単・フェアリー単・ほのお単
- **絵の比較**:同じポケモン同士の似ている度合いは0.95〜0.98、別のポケモンとは0.77以下で、はっきり区別できた

## 実行

スクショは他のプレイヤー名が写っているため、リポジトリには入れていません。手元のフォルダを指定して実行します。

```
python Vision/evaluate.py <スクショのフォルダ>
```
